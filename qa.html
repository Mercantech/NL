17 What is the roll-call (tællerække) rule? Practical

Roll-call is how we make sure nobody is missing. When we're gathered, we count aloud in order — so everyone hears immediately if someone is absent.

1 “One!”
→
2 “Two!”
→
3 “Three!”
→
4 “Four!”
→
n …last

When we're gathered, student 1 says their number aloud; then 2, 3, 4 — and so on. If counting stops, the next person is missing — we wait or find them. When the last number is called, the whole group is complete.

You'll get your number before we leave. Remember it and be ready to call it when we gather.
